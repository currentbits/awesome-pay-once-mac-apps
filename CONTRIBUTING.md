# Contributing

Thanks for contributing! Here's how to add an app.

## Requirements

The app must be:
- **Pay-once** — one-time purchase, no required subscription
- **Actively maintained** — updated within the last 12 months
- **Available on macOS** in 2026
- **Not free/open-source** — this list is specifically for paid apps (free lists exist elsewhere)

Apps with optional paid major version upgrades are fine (e.g. buy v5, optionally upgrade to v6 later). You always keep the version you bought.

## How to add an app

1. Fork this repo
2. Add the app to the correct category in `README.md`, in **alphabetical order**
3. Use this format:
   ```
   - [App Name](https://website.com) - One-line description of what it does. $XX
   ```
4. Submit a PR with the title: `Add [App Name]`

## Rules

- One app per PR (easier to review)
- Description should be one sentence, ending with the price
- Keep descriptions factual — no marketing superlatives
- If you're unsure about the category, pick the closest one
- Don't remove existing apps unless they've switched to subscription or are abandoned

## New categories

If the app doesn't fit any existing category, suggest a new one in your PR description.
